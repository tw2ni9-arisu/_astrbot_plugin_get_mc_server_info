# astrbot_plugin_get_mc_server_info

一个 AstrBot 插件，用于查询 Minecraft Java 版服务器状态。既可以通过传统命令操作，也支持 AstrBot 的 LLM Tool Calling，让模型直接调用插件完成查询和管理。

服务器数据按会话隔离，不同群聊或私聊之间互不影响。

当前版本：**v2.0.1**。

## v2.0.1 更新内容

- 新增 `/备用线路`、`/备用` 和 `/bak`，可为会话内已有服务器保存按添加顺序排列的备用线路；保存前会先验证地址能否访问。
- 主动查询已保存服务器时，优先访问主线路；主线路不可达时依次尝试备用线路，全部失败则返回 Offline 状态图。
- 无参数 `/查询` 会主动查询当前会话全部服务器，并使用实际响应线路更新服务器图标、玩家和延迟后生成合并图片。
- `/列表` 改为完全读取已有缓存，不会主动访问主线路或备用线路；列表图同时展示主线路、全部备用线路和最近缓存状态。
- 静默轮询会查询服务器的全部主备线路，并将成功结果中的最大延迟写入历史；所有线路均不可达时记录为 Offline。
- 模板改为目录化主/副模板结构：单服查询使用主模板，列表与全量查询使用副模板；内置终端副模板直接复用默认副模板。
- 新增 LLM Tool `add_mc_server_backup`。备用线路命令与 Tool 在群聊中仅管理员可用，私聊不要求管理员权限。
- 修复 AstrBot 以 `data.plugins` 命名空间加载插件时，`/查询` 和 `/列表` 无法导入副模板的问题。

## 功能

- 按会话添加、删除、重命名、重定向和查询服务器
- 为逻辑服务器保存有序备用线路，主动查询时自动故障转移
- 查询单个服务器，或把当前会话全部服务器合成为一张状态图片
- 获取服务器在线状态、延迟、版本、MOTD、在线玩家
- 下载玩家皮肤并渲染头像
- 渲染查询图片，包含 MOTD、延迟历史曲线、玩家列表
- 按历史点数与静默轮询间隔缓存延迟历史，可查询趋势、最高值和最低值
- 历史图保留断连/离线区间
- 服务器离线时沿用最近一次 MOTD，无记录时使用默认文案
- `/列表` 完全使用已有缓存生成图片，不主动访问服务器
- 静默轮询查询全部主备线路，并记录成功结果中的最大延迟
- 支持目录化主/副模板和模板热重载
- 提供 LLM Tool Calling 接口
- 缓存 Tool 查询结果、渲染结果、图标和头像
- 对网络查询命令和 Tool 调用做限流和并发控制
- 限制单会话服务器数、远端文本/玩家样本、图标/皮肤尺寸和渲染时间
- 自动清理过期缓存

> 说明：本项目部分代码由 AI 辅助生成，核心逻辑及测试由开发者完成。

## 命令

### 添加服务器

```
/添加服务器 <名称> <地址>
/添加 <名称> <地址>
```

### 查询服务器

```
/查询服务器
/查询服务器 <服务器名称>
/查询服务器 <服务器地址>
/查询
```

- `/查询服务器`：主动查询当前会话全部逻辑服务器，并返回一张包含实际响应线路、图标、延迟和玩家的图片。
- `/查询服务器 <服务器名称>`：查询已添加的逻辑服务器。先查询主线路，失败后按添加顺序尝试备用线路。
- `/查询服务器 <服务器地址>`：主线路或备用线路地址都会定位到同一逻辑服务器；未保存地址则执行直连查询（群聊默认仅管理员可用，私聊不受限）。
- `/查询`：`/查询服务器` 的简称。

命中备用线路时，图片地址和图标/玩家缓存使用实际响应的备用地址；所有线路都不可达时返回 Offline 状态图。

### 添加备用线路

```
/备用线路 <已有服务器名称> <备用地址>
/备用 <已有服务器名称> <备用地址>
/bak <已有服务器名称> <备用地址>
```

备用地址保存前会执行一次连接验证。一个会话内的主线路和备用线路地址不能重复，备用线路按添加顺序保存。该命令及其 LLM Tool 在群聊中始终仅管理员可用，不受 `mutation_requires_admin` 配置影响；私聊无需管理员权限。

### 删除服务器

```
/删除服务器 <名称>
/删除 <名称>
```

### 清除当前会话数据

```
/数据清除
```

删除当前会话保存的全部服务器及其对应缓存。该命令不会注册为 LLM Tool，必须由用户手动输入；群聊中始终仅管理员可用，私聊无需管理员权限。仍被其他会话引用的同地址缓存会保留。

### 重命名服务器

```
/重命名服务器 <旧名称> <新名称>
/重命名 <旧名称> <新名称>
```

### 重定向服务器

```
/重定向 <名称> <新地址>
```

只替换逻辑服务器的主线路，保存前会验证新地址能否连接；已有备用线路、名称和历史记录保持不变。新主线路不能与当前会话的任何主备地址重复。

安全限制：查询、添加备用线路、添加主线路和重定向仅允许解析到公网 IP；回环、私有、链路本地、保留和多播地址会被拒绝。群聊中的添加、删除、重命名、重定向和模板切换默认仅管理员可用，私聊不要求管理员角色；命令与 LLM Tool 执行相同权限检查。`/备用线路` 与 `/数据清除` 在群聊中始终仅管理员可用。

### 查看服务器列表

```
/服务器列表
/列表
```

列表完全使用已有缓存，不发起服务器查询。返回图片包含缓存图标（没有时由模板使用默认图标）、服务器名称、主线路与全部备用线路，以及最近缓存延迟。

### 模板

```
/模板
/模板 <模板名>
/模板 reload
/模板重载
```

- `/模板`：列出可用模板。
- `/模板 <模板名>`：切换当前会话模板。
- `/模板 reload`：兼容式重载；若不存在公开名称为 `reload` 的有效模板目录，则执行缓存重载。
- `/模板重载`：始终重新加载模板与查询图片缓存。

### 帮助

```
/帮助
/help
```

## LLM Tool

支持 Function Calling 的模型可以自动调用以下 Tool：

| Tool | 参数 | 功能 |
|------|------|------|
| query_mc_server | server | 查询服务器状态，server 可以是已保存名称或地址 |
| query_history_status | server | 查询已保存服务器在配置窗口内的缓存延迟趋势、最大值和最小值 |
| add_mc_server | name, address | 添加服务器 |
| add_mc_server_backup | server, address | 为已有服务器添加经过连接验证的备用线路 |
| delete_mc_server | server | 删除服务器 |
| rename_mc_server | old_name, new_name | 重命名服务器 |
| redirect_mc_server | name, new_address | 重定向服务器到新地址 |
| list_mc_servers | 无 | 列出当前会话服务器 |
| switch_mc_template | template | 切换查询图片模板 |
| resolve_server_name | hint | 根据模糊描述解析服务器候选 |

使用 LLM Tool 需要 AstrBot v4.18+，并启用 AstrBot 的 Tool 功能。

默认情况下，群聊普通成员只能查询当前会话已保存的服务器；群聊写操作和未保存地址直连需要管理员权限。`add_mc_server_backup` 在群聊中始终要求管理员权限。私聊不要求管理员角色。除备用线路和数据清除的固定权限外，可通过下方配置调整群聊权限。

`query_mc_server` 查询已保存服务器时返回 `primary_address`、实际响应的 `address`、`line_type` 和 `attempted_addresses`；`list_mc_servers` 同时返回有序主备线路。

## 处理流程

命令模式：`/查询 生存服` 进入业务层，按主备线路故障转移后渲染图片；无参数 `/查询` 使用副模板生成全服合并图片。

Tool 模式：用户自然语言交给 LLM，模型调用对应 Tool，插件返回 JSON，最后由 LLM 组织回复。

## 配置

插件配置由 `_conf_schema.json` 定义。

| 配置项 | 说明 |
|---------|------|
| silent_query_interval_seconds | 后台静默轮询间隔（秒） |
| history_limit | 每台服务器保留的延迟历史点数 |
| cache_ttl_seconds | 图标和头像缓存时长（秒） |
| status_timeout_seconds | 单次状态查询超时（秒） |
| auto_append_default_port | 地址未带端口时是否补全 25565 |
| mutation_requires_admin | 群聊写操作和模板切换是否仅限管理员（默认开启；私聊不受限） |
| direct_query_requires_admin | 群聊未保存地址直连查询是否仅限管理员（默认开启；私聊不受限） |
| query_all_concurrency | 全服查询并发数 |
| max_servers_per_session | 单个会话最多保存的服务器数 |
| avatar_download_concurrency | 头像下载并发数 |
| avatar_download_retries | 头像下载重试次数 |
| avatar_batch_timeout_seconds | 单服头像批处理总超时（秒） |
| render_timeout_seconds | 单次图片渲染总超时（秒） |
| query_result_cache_ttl_seconds | 单服查询渲染图片缓存时长（秒） |
| skin_api_url_template | 获取玩家皮肤的 HTTP(S) URL 模板，只允许 `{uuid}` 占位符 |

## 模板

模板目录为 `templates/`。每个立即子目录是一个模板包，例如：

```
templates/
├── default_method/
│   ├── default_method_query.py
│   ├── default_method_list.py
│   ├── default_method.png
│   ├── default_icon.png
│   └── HarmonyOS_SansSC_Medium.ttf
└── terminal_method/
    ├── terminal_method_query.py
    └── terminal_method_list.py
```

- 每个有效目录必须恰好包含一个 `*_query.py` 和一个 `*_list.py`；缺失或重复时不会出现在 `/模板` 列表中。
- 公开模板名取主模板文件名去掉 `_query` 后缀，与目录名无关。
- 主模板导出异步 `render_server_report_image`，副模板导出异步 `render_server_list_image`。
- 背景图可选，名称必须与公开模板名一致，后缀为 PNG/JPG/JPEG；默认图标可选，名称必须为 `default_icon`。
- 每个目录最多包含一个 `.ttf` 字体。
- 单服/直连查询使用主模板；`/列表` 和无参数 `/查询` 使用副模板。

内置默认副模板宽 900px，终端副模板直接复用默认实现并固定为 1100px；多台服务器卡片之间保持 20px 间距。

模板修改后可以用 `/模板重载` 热重载，不需要重启 AstrBot。

## FAQ

### AI 没有自动调用

检查 AstrBot 版本、模型是否支持 Function Calling、Tool 是否启用，以及人格 Prompt 是否禁用了 Tool。

### 为什么查询结果是一张图片

命令模式默认返回渲染图。Tool 模式返回 JSON，由 LLM 组织最终回复。

### `/列表` 和无参数 `/查询` 有什么区别

`/列表` 只读取已有缓存，不会连接服务器，适合快速查看已保存的主备线路和最近状态。无参数 `/查询` 会主动查询当前会话全部服务器，按主线路、备用线路的顺序完成故障转移，并更新实际服务器图标、玩家和延迟。

### Tool 会影响原有命令吗

不会。Tool 与命令共用同一套业务逻辑。
